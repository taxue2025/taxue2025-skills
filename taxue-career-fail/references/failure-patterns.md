# 失败模式与归因词典

> 诊断求职失败时的模式识别与归因追问。按需读取。

## 失败模式（快速匹配）

| 模式 | 特征 | 核心问题 |
|------|------|---------|
| **沉默型** | 投了N份，零回复 | 简历/渠道/岗位匹配 |
| **一轮游** | 有面试，但止步初面 | 简历引导了错误方向 / 面试准备 |
| **终面挂** | 走到最后但被刷 | 竞争者更强 / 文化匹配 / 薪资 |
| **Offer被鸽** | 口头答应但没发/发了被拒 | 公司问题 / 竞争Offer / 背调 |
| **入职失败** | 试用期没过 | 岗位错配 / 期望落差 |

## 格莱斯信号检测（对话中识别）

| 信号 | 表现 | 可能意味着 |
|------|------|-----------|
| **回避** | 某个环节被轻轻带过 | 那里是真正的痛点 |
| **转移** | 从「我的问题」突然跳到「市场不好」 | 防御机制启动 |
| **过度细节** | 对无关细节描述过多 | 用细节回避核心问题 |
| **情绪前置** | 先说感受再说事实 | 情绪遮蔽了真实原因 |
| **反复归因外部** | 「都是因为学历/年龄」 | 要么真外部障碍，要么拒绝面对内部问题 |

**点破句式**：「你说了不少关于{外部因素}，但一直没提{被回避的维度}——那里发生了什么？」

## 常见不成立归因（追问模板）

| 用户的归因 | 追问 |
|-----------|------|
| 「因为我是双非/二本」 | 「你投的公司里，有多少是明确卡学历的？」 |
| 「因为年龄大了」 | 「面试官有没有直接或间接提到年龄？还是你自己觉得？」 |
| 「因为市场不好」 | 「你身边有没有跟你背景类似但拿到Offer的人？」 |
| 「因为没经验/没背景」 | 「面试官说的'没经验'，具体指什么经验？」 |
| 「因为HR不专业」 | 「最近三次失败，有几个真的是HR/面试官的问题？」 |

## 心理学根因（面试表现层面）

| 根因 | 表现 | 怎么发现 | 修复方向 |
|------|------|---------|---------|
| **冲突回避** | 故事里没有张力、stakes、困难 | 追问「最难的部分是什么」，对方跳过 | 张力挖掘：把最难时刻放中心 |
| **叙事囤积** | 答案太长，结构崩塌 | 回答超 2 分钟还没到结论 | 约束练习：30/60/90 秒三版本 |
| **反射性「我们」** | 全是「我们做了 XX」 | 追问「你自己具体做了什么」 | 「我/我们」审计 |
| **地位焦虑** | 夸大贡献、用大词 | 追问细节答不上来 | 加真实限制、时间线 |
| **害怕犯错** | 答案保守、安全、谁都可以说 | 每个回答都很「正确」但没观点 | 尖锐观点练习 |
| **冒充者综合征** | 低估自己的贡献 | 量化时说「也就那样吧」 | 事实还原法 |
