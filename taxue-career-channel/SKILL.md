# taxue-career-channel：渠道策略

> 用错平台 = 在错池子里钓鱼/捞人。

---

## 求职者视角：渠道效率排序

| 优先级 | 渠道 | 适用场景 |
|--------|------|---------|
| ⭐⭐⭐ | 内推 | 有目标公司时，效率最高 |
| ⭐⭐⭐ | 猎头 | 中高端岗位，年薪30万+ |
| ⭐⭐ | 垂直社区/论坛 | 技术、产品、运营等特定领域 |
| ⭐⭐ | Boss直聘/猎聘 | 主动沟通，适合中小公司 |
| ⭐ | 公司官网 | 有明确目标公司时 |

### 核心策略
**不要海投。** 10份精准投递 > 100份海投。

### 人群渠道差异

| 人群 | 最优渠道 |
|------|---------|
| **应届生** | 校招 + 实习转正 + 校园宣讲会 |
| **转行者** | 垂直社区 + 目标行业人脉 + 猎头（转行岗） |
| **大龄** | 猎头 + 内推 + 行业人脉（避开公开海投的年龄筛选） |
| **中高层** | 猎头 + 高管人脉 + 被动的猎头联系 |
| **远程/自由** | 远程招聘平台 + 社区曝光 + 作品集引流 |
| **基层岗位** | 主流招聘平台全覆盖 + 到面率高者优先 |

### 战术级玩法
- **直接触达决策者**：Cold Email / LinkedIn 破冰公式（见 `references/channel-strategy.md` T0）
- **内推**：找利益共同体（学长/前同事/同圈），内推信模板
- **垂直社区**：GitHub/V2EX/Dribbble 等社区活跃度高
- **平台反向操作**：刷新活跃度、招呼语公式（5 种模板）、自检 4 铁律

**避坑**：常年挂着的岗位（可能是僵尸岗）、猎头套信息白嫖
