<p align="center">
  <a href="./README.md">中文</a> · <a href="./README_EN.md">English</a>

> **把任何模糊的问题，变成可执行的行动。**

踏雪寻仙的问题解决系统。不是工具箱，是工作流。

从 20+ 个实际场景中提炼方法论，做成Skill，覆盖问题解决、学习、创作、情绪、关系、职业、商业等全领域。

可在 Claude Code、Codex、Cursor、Trae Solo 等任意支持 Skill 的 Agent 上使用。

---

## 快速开始

### 安装

```bash
npx skills add taxueseek/taxueskills
```

安装后在 Agent 中输入 `/taxue`。

### 更新

重新运行安装命令即可：

```bash
npx skills add taxueseek/taxueskills -g --all
```

或使用内置升级工具：

```bash
/taxue-upgrade
```

## 完整技能表

### 核心解决层

| Skill | 功能 | 什么时候用 | 你会得到 |
|-------|------|-----------|---------|
| **taxue** | 入口路由 | 不知道从哪里开始 | 自动判断场景，0 秒直达 |
| **taxue-solve** | 解法引擎 | 有具体问题要解决 | 消解漏斗验证 + 模式匹配出方案 |
| **taxue-breakdown** | 任务拆解 | 事情太多、无从下手 | 可执行的最小行动清单 |
| **taxue-learn** | 学习方法 | 想学新东西、学了记不住 | 四步内化路径：收件箱→原子→内化→输出 |
| **taxue-content** | 内容创作 | 写文章、做脚本、出内容 | 选题门禁 + 五维诊断 + 可发布稿件 |
| **taxue-insight** | 本质洞察 | 想看透本质、底层逻辑 | 五步思维框架，穿透表象到结构 |
| **taxue-roundtable** | 决策圆桌 | 复杂决策、拿不定主意 | 多角色并行审视 + 可执行建议 |
| **taxue-build** | 系统构建 | 问题重复出现 | 六步编译法，经验变 Skill |

| Skill | 功能 | 什么时候用 |

## 工作流联动

Skill 之间通过入口自动推荐下一步。你不需要记住该用什么——系统帮你判断。

### 核心解决主线

```
solve（出方案了）
  ↓
breakdown（拆成可执行步骤）
  ↓
build（经验固化，下次直接调用）
```

### 内容创作线

```
content 需要选题 → 先 insight 看透本质
content 写不出来 → solve 解决核心卡点
content 诊断完 → 直接出终稿
```

### 情绪 → 行动线

```
calm（情绪解码，找到具体问题）
  ↓
solve（解决具体问题）
  ↓
relate（如果是关系问题，走沟通路径）
```

### 职业线

```
career（入口，判断阶段）
  ↓
direction（方向不清）→ resume（简历）
  ↓
channel（投递）→ interview（面试）
  ↓
offer（选择）→ onboard（入职）
```

### 持续积累线

```
solve / insight / business 走完有结论
  ↓
save（存档到本地）
  ↓
下次回来 → save --restore（接着上次继续）
  ↓
攒了多份 → save (手动整理)
```

### 学习线

```
learn（选课题）
  ↓
生成学习路径
  ↓
边学边输出
  ↓
实践遇阻 → solve
```

## 状态管理

复杂的诊断和问题解决不会在一次会话中完成。taxue 提供三种状态管理能力：

| 模式 | 功能 | 触发词 |
|------|------|--------|
| `--progress` | 保存问题解决中间状态 | 「保存进度」「存档」「记下现在到哪了」 |
| `--restore` | 恢复上次状态继续 | 「继续上次」「恢复」「上次到哪了」「接着做」 |
| `--decision` | 记录关键决策供复盘 | 「记一下这个决定」「记录决策」「复盘」 |

存档默认放在 `~/.taxue/sessions/`，每个项目隔离。

## 设计哲学

### 核心原则

**原则 1：先澄清，后解决**
问题不清，答案无用。80% 的纠结不是因为答案难找，是因为问题本身有问题。

**原则 2：够用就好，不要完美**
有限理性——追求当前够用的方案，不追求完美方案。

**原则 3：推动行动，不给建议**
不说「你可以考虑」，说「第一步做 X」。推动行动大于完美分析。

**原则 4：能固化，不复述**
重复的问题写成 Skill，一次建设长期受益。

### 哲学锚点

| 哲学家 | 映射 |
|--------|------|
| **亚里士多德「第一性原理」** | 剥离表象，找到底层机制。每个 Skill 都要能回答「本质是什么」 |
| **杜威「实用主义」** | 不能推动行动的思考都是空转。拆解到 15 分钟能开始才算拆完 |
| **德鲁克「有效性」** | 对谁有价值？做完后外部世界发生了什么变化？ |
| **阿德勒「目的论」** | 情绪在保护你避开什么？你真正害怕面对的是什么？ |
| **芒格「格栅思维」** | 单一视角必然盲视。用多个学科交叉验证 |
| **维特根斯坦「语言审查」** | 说不清的概念等于伪概念。拆到可操作才算真懂 |

## 常见使用路径

| 你的状态 | 自动路由到 | 会得到 |
|---------|-----------|--------|
| 方向模糊、纠结 | `taxue-solve` | 真正的问题定义 |

| 决策拿不定 | `taxue-roundtable` | 多视角审视+建议 |
