# 自我呈现完整指南

## 面试自我介绍

### 逻辑线（背这个，不背稿）

```
我是谁（一句话，定位）
    ↓
我做过什么（1-2 段最相关经历，有数字）
    ↓
我为什么在这里（为什么这个岗位/这家公司，要具体）
    ↓
我能带来什么（你判断自己能给团队解决什么问题）
```

### 示例（产品经理，3 年经验）

「我在消费互联网做了 3 年产品，主要方向是用户增长。
上一段在 XX，负责了拉新转化漏斗的优化，通过改造落地页和激励机制，把新用户 7 日留存从 28% 提到 41%。
我来面试你们这个岗位，是因为你们在做 XX 方向——这正好是我接下来想深耕的，
而且我在拉新和数据分析方面的经验应该能直接用上。」

### 常见错法和修法

| 错法 | 问题 | 修法 |
|------|------|------|
| 从大学开始按时间顺序讲 | 讲完 5 分钟，面试官分心 | 从最相关的经历开始，倒序 |
| 「我是一个有责任心的人」 | 没有信息量 | 用经历说明，不用形容词 |
| 「我的缺点是追求完美」 | 假谦虚，面试官听腻了 | 不要在自我介绍里说缺点 |
| 把简历内容念一遍 | 面试官已经看过简历了 | 补充简历里没有的：判断力、为什么来 |

## Cover Letter 模板

### 三段结构

**第一段：为什么是这家公司**
具体说一个你了解的细节（产品/业务方向/团队做的事），说为什么它吸引你。
不可以说：「贵公司是行业领先企业，我一直仰慕」

**第二段：为什么是你**
2 条经历，每条一句话，有数字，和这个岗位的核心要求对应。

**第三段：期待**
「我希望有机会进一步和您沟通，了解更多关于 [岗位/团队] 的情况。」

### 示例

```
[HR 姓名]，你好：

看到 [公司] 在招 [岗位]，我很感兴趣。
你们最近在 [具体业务方向] 的探索让我觉得方向很对——
这正是我接下来想深入的领域。

我在 [前公司] 做了 X 年 [岗位]，
主要成果是：① [经历1，有数字]；② [经历2，有数字]。
这两段经历和你们 JD 里提到的 [核心要求] 高度匹配。

希望有机会进一步交流。简历附件里有更详细的信息。

谢谢，
[姓名]
```

## 内推请求模板

### 找认识的人内推

```
[姓名] 好，打扰一下。

我最近在看新机会，关注到 [公司] 在招 [岗位]（[JD链接]）。
我的背景是 [一句话：X年XX经验，主要做XX]，
觉得和这个岗位比较匹配，主要是 [一个最相关的点]。

请问可以帮我内推一下吗？简历在附件里。

不麻烦的话，真的很感谢！
```

### 找陌生人内推（LinkedIn / 脉脉）

```
[姓名] 好，冒昧打扰。

我在关注 [公司] 的 [岗位]，看到您在那里工作，
想简单了解一下团队和岗位的情况，您方便的话能聊 15 分钟吗？

我的背景是 [一句话]，简历在附件里。

感谢您的时间，不打扰了。
```

**要点**：要求具体（聊 15 分钟，不是「指导」）、给对方最少的决策成本。

## LinkedIn / 脉脉 个人资料优化

**摘要（Summary）**：和自我介绍逻辑线一样，但写成第三人称。

**经历描述**：和简历对齐，但可以更口语化。每段加 2-3 个行业关键词（方便被搜索到）。

**开放到机会**：设置「Open to Work」不会被现任公司看到（LinkedIn 有过滤设置）。

**被猎头联系时**：先了解岗位详情，不要第一时间拒绝——是否合适，看清楚再决定。
