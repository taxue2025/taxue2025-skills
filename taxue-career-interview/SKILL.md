# taxue-career-interview：面试/离职引擎

> 面试不是考试，是双向选择。离职不是结束，是关系转换。

---

## 模拟面试模式

### 初始化

开始模拟面试前，收集必要信息：
1. **目标岗位**（必需）：什么岗位？面试什么级别？
2. **简历/背景**（可选但推荐）：用于基于简历出题
3. **目标公司**（可选）：不同公司面试风格不同（大厂重算法、外企重英语、创业公司重综合）
4. **面试轮次**（可选）：技术面/行为面/系统设计/综合

### 题目分类体系

为每道题标记分类，确保覆盖全面、难度递进。

**技术面：**
- `DS-Algo` - 数据结构与算法
- `Network` - 计算机网络（TCP/IP、HTTP、DNS）
- `OS` - 操作系统（进程线程、内存管理）
- `Database` - 数据库（索引、事务、分库分表）
- `Lang-Runtime` - 编程语言与运行时
- `Framework` - 框架与中间件
- `Arch-Design` - 架构设计（微服务、高可用、分布式）
- `Scenario` - 场景题（故障排查、性能优化）
- `Coding` - 手写代码题

**行为面：**
- `Behavior-Project` / `Behavior-Team` / `Behavior-Conflict` / `Behavior-Fail` / `Behavior-Plan` / `Behavior-Leadership`

**系统设计：**
- `SD-Overall`（整体架构）/ `SD-Scale`（高并发高可用）/ `SD-Data`（数据存储）/ `SD-Realworld`（真实系统复现）

**题目日志**：内部维护本轮题目记录，避免重复（同分类不连续 2 题以上）、保证覆盖、难度递进。

### 出题策略

- 根据简历技术栈问深度问题（简历写「精通 React」→ 深挖 React 原理）
- 根据项目经验问细节（「你在 XX 项目用了 Redis，讲讲缓存策略」）
- 针对潜在薄弱点压力测试（简历没写但岗位需要的能力）
- 追问量化成果（「你说性能提升 50%，怎么做的？」）

**出题可脚本化**：`python3 scripts/question_gen.py --jd jd.txt` 自动生成题目（--round tech/behavior/design 限类型，--count 限数）。脚本生成基础题，结合简历深挖。

### 提问与反馈

**每轮一问**，等用户回答后给结构化反馈：

```
评分: X/10
分类: [题目分类]
参考思路: （1-2 句关键点）
追问: （根据回答深入 1 问）
```

**评分维度**：回答结构（STAR 是否完整）/ 深度（是否触及本质）/ 表达（是否清晰有条理）。

### 结束总结

面试结束输出完整总结：整体评分、题目覆盖分析（哪些分类没考到）、优势、待改进、下次重点。

## 求职者视角：面试准备

1. **研究公司**：产品、竞品、最近新闻、面试官背景
2. **准备故事库**：3-5个核心项目/经历，每个用STAR框架
3. **准备问题**：问面试官的问题——「这个岗位最大的挑战是什么」>「你们公司怎么样」

### 行业面试差异

| 行业 | 面试侧重点 | 准备要点 |
|------|-----------|---------|
| **技术/研发** | 算法 + 系统设计 + 项目深挖 | 刷 LeetCode，准备系统设计框架 |
| **产品/运营** | 案例拆解 + 数据 sense + 用户洞察 | 准备 2-3 个完整产品案例，带数据 |
| **金融/咨询** | 案例分析 + 逻辑表达 + 抗压 | 练 Case Interview，准备框架 |
| **设计/创意** | 作品讲解 + 设计思路 + 品味 | 准备作品故事线，讲决策过程 |
| **销售/市场** | 场景题 + 抗压 + 结果导向 | 准备业绩案例，练临场应变 |
| **管理岗** | 团队管理 + 决策案例 + 格局 | 准备带团队的战果与教训 |
| **外企** | 英语能力 + 跨文化 + 行为面 | 练英语自我介绍，准备 STAR 英文版 |

### 面试后复盘

1. 哪些问题答得好？为什么？
2. 哪些问题卡住了？缺什么知识？
3. 下次同类问题怎么答？

## 薪资谈判

**原则：先拿到Offer，再谈薪资。**
1. 了解市场薪资范围
2. 给出一个范围：「我的期望是XX-XX」
3. 如果低于期望：「这个薪资的上升空间是怎样的？」

---

## 离职

**原则：好聚好散，不说公司坏话。**
1. 先找好下家，再提离职
2. 离职原因说「个人发展」
3. 交接文档完整，给前东家留个好印象

---

## 雇主视角

### 面试候选人
- 行为面试法：问「你做过什么」>「你会怎么做」
- 文化匹配：问「你上一份工作中最让你崩溃的事是什么」

## 下游协作

| 触发条件 | 推荐 |
|----------|------|
| 面试完了有Offer | `taxue-career-offer` |
| 面试挂了 | `taxue-career-fail` |
| 离职后需要规划下一步 | `taxue-career-direction` |

## DO NOT

- 从零创建新 skill → `skill-creator`
- 需要选Offer/谈薪资 → `taxue-career-offer`（interview 只管面试和离职，选Offer走 offer）
- 需要改简历 → `taxue-career-resume`
