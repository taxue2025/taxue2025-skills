# 素材库引用指南

> 哪些原子可以安全引用，哪些必须过滤

---

## 可用原子类型

以下类型的原子可以安全引用，不泄露个人经历：

### 投资类（通用原则）
- 投资心态
- 投资智慧
- 投资方法
- 资产配置
- 投资原则
- 投资哲学
- 投资本质
- 投资认知

**示例可用内容**：
- 「市场不会为你的认知买单，只会为你的行动和承受能力付费」
- 「一年翻倍者众，三年翻倍者寡」
- 「以均衡配置为盾，以风格认知为矛」

### 思维类
- 思维方式
- 思维模型
- 问题解决
- 决策方法

**示例可用内容**：
- 「复利思维：微小优势的长期累积」
- 「锚点才是杠杆」

### 学习类
- 学习方法
- 学习策略
- 知识管理

**示例可用内容**：
- 「收藏夹是信息的坟墓，提炼过的笔记才是资产」
- 「如果你不能简单地解释一件事，那你就还没有真正理解它」

### AI类
- AI使用
- AI技巧
- AI思维
- AI哲学

**示例可用内容**：
- 「不要把AI当作提效工具，要把它当作员工」
- 「提示词写得清楚，是因为你想得清楚」

### 创作类
- 创作洞察
- 创作原则
- 写作技巧

**示例可用内容**：
- 「账号会死，平台会倒，算法会变。但真正有价值的内容和它所建立的信任关系，将永远是你的核心资产」
- 「文字洁癖是底线」

### 其他通用类型
- 长期主义
- 复利
- 洞见
- 认知差

## 禁用原子类型

以下类型的原子包含个人经历，严禁引用：

### 含具体时间/事件
- ❌ 投资故事
- ❌ 年度回顾
- ❌ 投资历程
- ❌ 关键词（年度个人关键词）

### 含个人经历描述
- ❌ 任何提到 "2016年"、"熔断"、"医疗回撤"、"2025全天候" 的内容
- ❌ 任何提到 "我"、"我的组合"、"我的经历" 的内容
- ❌ 任何提到具体持仓、具体盈亏的内容

### 示例禁用内容
- ❌ 「2016年熔断，是我这十年里最深的一道印记」
- ❌ 「2021年医疗基金回撤超过40%」
- ❌ 「我的全天候投资组合...」
- ❌ 「定投10年的经验告诉我...」

## 引用规范

### 引用格式

引用原子时，只使用：
- content（内容）
- when_to_use（使用场景）

不使用：
- id（不透露具体编号）
- source（可能包含个人经历描述）

### 引用示例

**正确引用**：
> 关联思维：「锚点才是杠杆」——面对选择困难时，先找到不变的锚

**错误引用**：
> 关联素材库原子 tx_601：「锚点才是杠杆」，来源：2025年个人投资总结

---

## 快速判断清单

引用前过三道门：

- [ ] 这个原子提到具体时间/年份了吗？
- [ ] 这个原子提到 "我" 的个人经历了吗？
- [ ] 这个原子提到具体持仓/盈亏了吗？

任何一条是，就不引用。

---

## 替代方案

如果话题涉及投资经历相关，但没有安全的原子可用，怎么办？

**用通用思维框架替代**：
- 不说「我经历过2016年熔断」，说「历史上多次出现」
- 不说「我的组合回撤30%」，说「市场极端情况下」
- 不说「我定投10年的经验」，说「长期定投的纪律」

**用抽象原则替代具体经历**：
- 具体：「2021年医疗回撤教会我...」
- 抽象：「市场极端回撤时，纪律比判断重要」

## 查询命令

安全查询可用原子的命令：

```bash
# 按类型查询（安全类型）
python ~/.config/agents/skills/踏雪素材库/atoms-query.py --type "投资心态"
python ~/.config/agents/skills/踏雪素材库/atoms-query.py --type "思维方式"
python ~/.config/agents/skills/踏雪素材库/atoms-query.py --type "学习方法"

# 按标签查询（安全标签）
python ~/.config/agents/skills/踏雪素材库/atoms-query.py --tags 投资 长期
python ~/.config/agents/skills/踏雪素材库/atoms-query.py --tags 思维 决策
```

避免使用可能返回个人经历的查询：
```bash
# 避免：可能返回年度回顾
python ~/.config/agents/skills/踏雪素材库/atoms-query.py --type "年度回顾"

# 避免：可能返回个人故事
python ~/.config/agents/skills/踏雪素材库/atoms-query.py --type "投资故事"
```
