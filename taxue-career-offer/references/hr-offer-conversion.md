# Offer 转化与候选人体验

## Offer 接受率低的五个根因

| 根因 | 信号 | 解法 |
|------|------|------|
| 薪资低于预期 | 候选人拒绝时提到「其他机会」 | 在面试中期就了解期望，有空间就拉满 |
| 流程太慢 | 候选人「已接受其他 offer」 | 关键候选人压缩流程，3 个工作日内出结论 |
| 面试体验差 | 候选人不回消息 | 改进面试官培训，给候选人正向反馈 |
| 信息不透明 | 候选人「还在考虑」超过 5 天 | 主动问顾虑，直接解答 |
| Offer 内容不清楚 | 候选人问很多细节问题 | 发 offer 时附上清晰的 package 说明 |

---

## Offer 发出的标准流程

```
1. 电话通知（offer 发出前先打电话）
   ↓
2. 发送书面 offer（包含 package 明细）
   ↓
3. 24 小时内跟进（「有没有问题想了解」）
   ↓
4. 3-5 个工作日等待（不催）
   ↓
5. 候选人决策截止日前 1 天轻度跟进
```

**Offer 电话怎么打**：
「你好，我是 [公司] [HR 姓名]，恭喜你通过了 [岗位] 的所有面试环节，我们决定向你发出 offer。接下来我说一下主要条件，你看看有没有问题……」
先口头确认意向，再发书面 —— 避免书面 offer 直接被拒，浪费双方时间。

---

## Offer 书内容清单

候选人看 offer 时的核心关注点，全部写清楚：

- [ ] 职位名称和职级
- [ ] 入职日期
- [ ] Base 薪资（月薪 × 几个月）
- [ ] 奖金机制（比例、发放条件、发放时间）
- [ ] 股票/期权（数量、归属周期、行权价）
- [ ] 社保基数
- [ ] 试用期时长和试用期薪资
- [ ] 有效期（通常 3-5 个工作日）

任何一项不清楚，候选人都可能因为误解而拒绝。

## 候选人谈薪应对

**候选人说「能不能再高一点」**：

判断：这个候选人值吗？
- 值 → 去内部争取空间，给候选人 1-2 个工作日等待
- 不值 → 「我们已经是这个岗位的最高预算了，我帮你看看其他部分有没有空间」
- 卡在内部上限 → 「我们的 base 上限是 X，但签字费或者第一年奖金保底我可以去争取」

**不要说**：「就这么多了，爱要不要。」——这是最快失去候选人的方式。

---

## 候选人放鸽子（Ghosting）处理

**入职前 1 周没回消息**：打电话确认，不发消息。
**候选人说「临时有变」**：问清楚是什么变——是有更好的 offer，还是内部留用，还是个人原因。
- 有更好的 offer → 问清楚差距，能追就追，不能追就接受
- 内部留用 → 接受，问是否可以保持联系（6 个月后可能再出来）
- 个人原因 → 了解，表示理解，留好印象

**礼貌结束**：候选人圈子很小，你今天的态度影响你公司的口碑。

---

## 候选人体验优化

**面试体验对 offer 接受率的影响**：

好的面试体验 = 候选人即使薪资少一点也愿意来
坏的面试体验 = 候选人薪资再高也会犹豫

**提升面试体验的动作**：
- 面试前：提前告知地点/方式/流程（不要让候选人猜）
- 面试中：给候选人足够的说话时间（面试官说话不超过 40%）
- 面试后：48 小时内给结果（哪怕是「还在走流程」）

**不通过的候选人怎么拒**：

```
[候选人姓名] 你好，

感谢你参与 [公司] [岗位] 的面试，
我们认真考虑了你的背景，非常遗憾这次暂时没有缘分。

如果未来有合适的机会，我们会再联系。
祝你求职顺利。

[HR 姓名]
```

不要消失——「已读不回」是最差的候选人体验，对公司口碑伤害最大。
