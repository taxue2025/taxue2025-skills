# taxue-build：系统构建

把个人解法变成可复用资产。六步编译法：目的 → 标准 → 边界 → 界面 → 验收 → 迭代

## 六步编译

1. **目的**：这个 Skill 解决什么问题？一句话说清。
2. **标准**：什么叫「做好了」？输出格式、质量红线。
3. **边界**：什么时候**不**用？避免滥用。
4. **界面**：用户怎么调用？触发词、输入、输出。
5. **验收**：测3个真实场景，通过才算完成。
6. **迭代**：用起来，根据反馈改。

## 内化案例：踏雪的学习方法论

不是「教你学习」，而是展示「我怎么从素材中长出能力」。

### 关键节点

**2018 | 从零构建 → 碎片整理**
```
输入：格雷厄姆《聪明的投资者》
处理：提取3个核心概念（安全边际/市场先生/能力圈）
输出：手写笔记 → 第一次理解「价值投资」
```
→ **领悟**：先建地图，再填细节。一本经典吃透，胜过100篇快餐。

**2020 | 碎片整理 → 素材库**
```
输入：收藏夹500+文章、读书笔记、投资复盘
处理：建立「踏雪素材库」结构（收件箱/核心资产/冷库）
输出：可检索、可复用的知识原子
```
→ **领悟**：不要存文章，要存「知识原子」。给每个素材打标签：什么时候用？

**2023 | 交互内化 → AI方法论**
```
输入：大量AI工具试用记录
处理：苏格拉底追问——「提示词工程的核心是什么？」
      发现是「精确描述需求」而非「学更多技巧」
输出：AI创作方法论 → 系列文章 → Prompt武器库
```
→ **领悟**：输出倒逼输入。写不出来，说明没真懂。

**现在 | 系统输出 → Skill体系**
```
输入：8年投资+创作经验、素材库、方法论
处理：六步编译法，把经验变成可调用 Skill
输出：taxue 系列、踏雪素材库、风格系统
```
→ **领悟**：能固化，不复述。一次建设，长期受益。

## 怎么固化你的经验

**Step 1：识别重复**
- 哪些问题你回答了3次以上？
- 哪些流程你每次都在重新想？

**Step 2：提取骨架**
- 把步骤写成清单（不要解释，只写动作）
- 把判断标准写成规则（if X then Y）

**Step 3：写成 Skill**
```markdown
---
name: 你的skill
description: |
  一句话说明用途。
  触发：关键词
---

# Skill 名

## 触发条件
什么时候用这个 Skill

## 执行步骤
1.
2.
3.

## 输出格式
```

**Skill 写完后，做图尔明质量检验**——每条核心规则必须能填写：

```
主张：该做 {X}
数据：因为 {可观察的事实或案例Y}
保证：Y 能支撑 X，底层逻辑是 {Z}
限定：在 {反例条件} 下不适用
```

写不出「保证」的规则是废话——用户照做会卡住，删掉或重写。

**Step 4：测试迭代**
- 用3个真实场景测试
- 根据反馈调整，直到「不用想就能用」

**信号层检验**（测试时额外观察）：
- **沉默信号**：真实使用者在哪个步骤停下来了？那里就是文档的盲区
- **保留信号**：哪些步骤措辞让人「感觉懂但不敢行动」？那里就是表述太模糊
- 沉默和保留出现的地方，比正面反馈更有改进价值

## 参考：踏雪素材库的内化流

```
收件箱（新素材）
    ↓ 每周清理
分类筛选 → 噪音删除 / 信号归档 / 模糊留置
    ↓
核心资产（可复用）
    ↓ 月度盘点
方法论提炼 → 框架沉淀
    ↓
Skill固化 → 系统输出
```

**核心原则**：每个素材必须回答——什么时候用？对谁有用？
