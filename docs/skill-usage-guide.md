# Taxue Skills 使用指南

> 26 个 Skill，每个怎么用、什么时候用、用完去哪。

---

## 核心技能

### taxue（入口路由）

**触发**：`/taxue` 或描述你的问题即可

**做什么**：自动判断你的问题类型，路由到正确的子 Skill

**原则**：只路由，不解决。它不做分析、不输出方案、不给建议——只把你送到对的地方。

**未匹配时**：展示能力列表等你选择

---

### taxue-solve（解法引擎）

**触发**：「怎么办」「卡住了」「出错了」「要解法」「给个方案」

**流程**：
1. 消解漏斗 5 层验证（问题真的存在吗？）
2. 模式匹配选方案
3. 输出模板/话术/清单

**输出**：解法 + 模板 + 下一步建议

**用完去**：拆任务 → `taxue-breakdown`；固化为 Skill → `taxue-build`；存档 → `taxue-save`

---

### taxue-breakdown（任务拆解）

**触发**：「帮我拆一下」「事情太多」「怎么安排」「复杂任务」

**核心原则**：拆到 15 分钟能开始才算拆完

**输出**：任务清单（最小可执行单位 + 优先级 + 时间估计）

**用完去**：遇阻 → `taxue-solve`；存档 → `taxue-save`

---

### taxue-learn（学习方法）

**触发**：「怎么学」「想掌握」「学了记不住」「怎么入门」

**方法**：四步内化法 — 收件箱 → 原子 → 内化 → 输出

**哲学**：费曼「不用术语能解释清楚才算真懂」+ 杜威「做中学」

**输出**：学习路径 + 费曼测试 + 输出计划

**用完去**：实践遇阻 → `taxue-solve`

---

### taxue-content（内容创作）

**触发**：「写一篇」「创作」「小红书」「公众号」「做个内容」

**流程**：
1. 选题门禁（5 个问题判断是否值得做）
2. 初稿
3. 五维诊断
4. 终稿

**输出**：可发布内容 + 选题判断

**用完去**：积累素材 → `taxue-material`；激发灵感 → `taxue-weread`

---

### taxue-insight（本质洞察）

**触发**：「本质是什么」「底层逻辑」「核心矛盾」「第一性原理」

**方法**：五步思维框架（看见表层 → 追问结构 → 跨域映射 → 验证边界 → 指向行动）

**输出**：一句让人愣住的判断 + 支撑逻辑

**用完去**：执行 → `taxue-breakdown`；存档 → `taxue-save`

---

### taxue-roundtable（决策圆桌）

**触发**：「多角度看看」「开圆桌」「讨论一下」「帮我看看这个选择」

**模式**：
- 快速模式：一轮输出，带走 2-3 条可执行建议
- 深入模式：多轮讨论

**角色**：视问题自动匹配（实用型/分析型/激进型/保守型）

**输出**：多角色建议 + 综合行动方案

**用完去**：做决策 → `taxue-solve`

---

### taxue-calm（情绪解码）

**触发**：「焦虑」「内耗」「自我怀疑」「心态崩了」「睡不着」

**核心**：情绪是信号，不是问题。不安慰，不鸡汤——只解码，给路径。

**方法**：追踪触发事件 → 替换原始解释 → 设定最小下一步

**输出**：情绪来源分析 + 具体行动

**用完去**：解决问题 → `taxue-solve`；关系问题 → `taxue-relate`

---

### taxue-relate（关系沟通）

**触发**：「关系」「沟通」「冲突」「谈判」「边界」「跟老板谈」

**核心**：不调解，不站队——只分析结构，给工具。

**方法**：利益结构分析 → 替代方案 → 沟通策略 → 执行话术

**输出**：关系图谱 + 沟通策略 + 话术

---

### taxue-speak（说话练习）

**触发**：「说话不流畅」「表达不好」「紧张」「说不出」

**核心**：四种说话领地，四套法则。不是指导你「要自信」——是给你框架练。

**领地**：
- 关系维系型（日常交际）
- 事务达成型（汇报/谈判/说服）
- 思想情感表达型（深度表达）
- 公开展示型（演讲/口播/即兴）

**输出**：定位 + 练习任务 + 框架

**用完去**：实战沟通 → `taxue-relate`

---

### taxue-business（商业诊断）

**触发**：「这个生意能不能做」「商业模式」「值不值得做」

**方法**：投资原理映射（能力圈/护城河/安全边际/复利）

**输出**：快速判断结果（自洽/不自洽/需验证）

**用完去**：需深度诊断 → `taxue-solve`；存档 → `taxue-save`

## 职业发展系列

### taxue-career（职场入口）

任何职业问题的第一站。路由到对应子 Skill。

### taxue-career-direction（职业方向）

转行、方向迷茫、职业规划。

### taxue-career-resume（简历诊断）

写简历、改简历、简历投了没回应。

### taxue-career-channel（投递渠道）

去哪个平台、怎么投、怎么跟进。

### taxue-career-interview（面试准备）

面试慌、不知道问什么、谈薪。

### taxue-career-offer（Offer 选择）

多个 Offer 怎么选、怎么谈。

### taxue-career-onboard（入职适应）

新环境、新团队、前 90 天。

### taxue-career-fail（职场失败复盘）

被拒、被裁、失败重建。

**职业线完整路径**：
```
career → direction → resume → channel → interview → offer → onboard
                                               ↓ fail
                                          career-fail → direction
```

## 工具与基建

### taxue-build（系统构建）

**触发**：「写个 skill」「固化流程」「问题重复出现」

**流程**：六步编译法（目的→标准→边界→界面→验收→迭代）

**输出**：可复用的 SKILL.md

### taxue-upgrade（版本管理）

**触发**：「升级」「检查更新」「版本」

**功能**：检测版本差异、备份、升级、回滚

**备份位置**：`~/.claude/skills/.backup/` 或 `.taxue-backups/`

### taxue-skill（Skill 工程）

**触发**：「分析我的skill」「优化skill」「怎么写skill」

**功能**：分析现存 SKILL.md，优化结构，设计新 Skill

### taxue-material（素材管理）

**触发**：「积累素材」「整理素材」「素材库」

**功能**：管理创作素材，积累灵感，整理案例库

**用完去**：创作内容 → `taxue-content`

## 状态管理

### taxue-save（状态存档）

**三合一模式**：

| 模式 | 用户说 | 做什么 |
|------|--------|--------|
| `--progress` | 「保存进度」「存档」「记下现在到哪了」 | 结构化保存当前解决状态 |
| `--restore` | 「继续上次」「恢复」「上次到哪了」「接着做」 | 拉出最近存档，问从哪继续 |
| `--decision` | 「记录决策」「复盘」「之前的判断对吗」 | 记录关键决策供后续复盘 |

**存档路径**：`~/.taxue/sessions/{项目名}/`

## 工作流总览

```
输入问题 → /taxue 入口路由
              │
              ├── 需要解决 → solve
              ├── 需要拆解 → breakdown
              ├── 需要学习 → learn
              ├── 需要创作 → content → material/weread
              ├── 需要洞察 → insight
              ├── 需要多视角 → roundtable
              ├── 情绪问题 → calm → solve/relate
              ├── 关系问题 → relate
              ├── 表达问题 → speak → relate
              ├── 商业问题 → business
              ├── 职业问题 → career（6 个子 Skill）
              └── 其他 → 展示能力列表
              
任何有结论 → save（存档）
多次存档后 → 整理归档
问题重复 → build（固化为 Skill）
```
