# 试用期生存手册

> 前 90 天决定你能不能留下来、留得好不好。这三个月不是「适应期」，是「证明期」——证明你能解决他们招你进来要解决的问题。

## 试用期法律红线（保护自己）

| 事项 | 法律规定 | 说明 |
|------|---------|------|
| 试用期上限 | 合同 3 年以下 ≤ 1 个月；3 年以上 ≤ 6 个月 | 超过法定上限无效 |
| 试用期薪资 | ≥ 转正薪资的 80% | 低于 80% 违法 |
| 试用期次数 | 同一单位只能约定 1 次 | 续签不得再设试用期 |
| 解雇条件 | 必须证明「不符合录用条件」 | 要有明确录用标准 + 考核记录 |
| 社保缴纳 | 试用期内必须缴 | 不缴违法 |

**如果遇到试用期被随意解雇**：要求书面说明理由 + 考核依据；协商补偿（N 或 0.5N）；不成再走劳动仲裁。

## 转正对齐（第 60 天主动做）

提前 2-4 周和 leader 对齐转正：
1. **主动约谈**：「我想在转正前和您对齐一下我这几个月的表现」
2. **准备证据**：列出入职以来的 3 个成果（做了什么 + 结果 + 对团队的价值）
3. **确认标准**：「转正主要看哪几个方面？我现在做得怎么样？」
4. **处理差距**：如果 leader 提到不足，当场问「您觉得我该怎么改进？」并给改进计划

## 前 30 天生存法则

1. **找关键人**：谁是决策者、谁影响决策、谁执行。前 30 天最重要的产出是「搞清楚这潭水怎么游」
2. **跟 leader 深度聊一次**：他对你的期望是什么、怎么算做得好、什么优先级最高
3. **多听少说**：前 30 天发表颠覆性意见是找死。你不了解政治格局和历史遗留问题
4. **Quick Wins**：找出团队最痛但容易解决的小问题，60 天内搞定它建立口碑

## 转正答辩/汇报结构

| 部分 | 内容 |
|------|------|
| 做了什么 | 3 个成果，每个「背景→动作→结果→数字」 |
| 学会了什么 | 团队协作方式、业务逻辑、工具链 |
| 下一步计划 | 未来 3 个月想做什么，体现思考深度 |
| 需要的支持 | 主动提需求，体现主动性与边界感 |
