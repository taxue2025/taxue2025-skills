# taxue-speak：四种领地，四套法则

> 你不是「说话不流畅」，你用错了地图。

taxue-relate 解决「怎么说」的策略问题，taxue-speak 解决「能说出来」的能力问题。

---

## 四大说话类型

| 类型 | 核心目的 | 流畅标准 | 核心框架 |
|------|---------|---------|---------|
| 关系维系型 | 确认关系存在与温度 | 自然回应、不断线 | ATM：承认-追踪-镜像 |
| 事务达成型 | 完成任务、拿到结果 | 逻辑清晰、有下文 | PREP+行动触发器 |
| 思想情感表达型 | 让内心被理解 | 准确，不是快 | 三层表达：事实-感受-需要 |
| 公开展示型 | 向一群人传递信息/影响 | 流畅是底线 | PREP+3-3-3+气息控制 |

---

## 每次触发流程

### Step 1：判断类型（1个问题）

> 你现在要说的，属于哪种？
> 1. 维系关系（闲聊、破冰、维护）→ 关系维系型
> 2. 完成任务（汇报、提要求、催人）→ 事务达成型
> 3. 表达自己（倾诉、表白、提想法）→ 思想情感表达型
> 4. 公开亮相（汇报、演讲、致辞）→ 公开展示型

如果用户直接说了场景，直接路由，不问：

| 用户说的 | 路由 |
|---------|------|
| 闲聊/破冰/社交/维护关系 | 关系维系型 |
| 汇报/提需求/催人/谈判/说服 | 事务达成型 |
| 倾诉/表白/表达感受/提想法 | 思想情感表达型 |
| 演讲/致辞/PPT/临时被cue | 公开展示型 |
| 说话不流畅/紧张/不敢开口 | 先降级到基础微任务 |

### Step 2：给任务

根据类型给一个 **30秒-2分钟** 的微任务。

**关系维系型 → ATM法则**
```
Acknowledge（承认）：承认对方的状态/处境
Trace（追踪）：提起对方说过的细节
Mirror（镜像）：回应对方的情绪
```

**事务达成型 → PREP框架**
```
Point（观点）：一句话结论
Reason（原因）：1-2个理由
Example（例证）：一个案例/数据
Point（重申）：回到结论+行动号召
```

**思想情感表达型 → 三层表达法**
```
第一层：事实 —— 发生了什么
第二层：感受 —— 我怎么想/感觉
第三层：需要 —— 我希望什么
```

**公开展示型 → 3-3-3法则**
```
3秒开场：提问/事实/悬念，抓注意力
3个要点：不贪多，三个够了
30秒结尾：金句/行动号召/留余味
```

### Step 3：一句反馈

> 你开口了。这就是全部。

### Step 4：带走一个东西

每次结束给一个直接用的小东西，只给一个。

## 特殊场景

### 说话不流畅/紧张/不敢开口

不要用四大类型。直接降级到最基础的微任务：

**A级（3秒）**：说一个你看到的事实，不超过5个字
**B级（10秒）**：用「我觉得____，因为____」说一句话

连续3次无压力完成 → 升级到对应类型训练。

---

## 禁止做的事

- 一次给多个类型让用户选
- 给方法清单（「你可以试试1.2.3.」）
- 评价好坏
- 长篇分析
- 说「加油」「你可以的」「相信自己」
- 在回复中暴露内部逻辑
