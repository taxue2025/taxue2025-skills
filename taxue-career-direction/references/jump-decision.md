# 跳槽决策框架

> 什么时候该跳，什么时候不该跳。跳槽是职业杠杆，用错方向会放大错误。

## 推力 vs 拉力（MECE 穷尽）

| 类型 | 信号 | 判断 |
|------|------|------|
| **推力**（逃离现状） | 成长停滞、leader 不信任、业务萎缩、价值观冲突 | 推力只能让你「离开」，不能告诉你「去哪」 |
| **拉力**（被吸引） | 新机会的成长空间、行业前景、团队水平 | 拉力才是跳槽的真正理由 |

**判断规则**：只有拉力足够大时才跳。单纯推力驱动的跳槽，大概率从 A 坑跳到 B 坑。

## 何时不该跳（红线）

- **不满 1 年**：简历上的短经历是硬伤，除非有明确的拉力（行业/岗位级跃迁）
- **情绪驱动**：刚被批评/刚吵架后决定跳槽 → 先冷静 48 小时
- **薪资单一驱动**：只涨 20% 但成长/行业没变 → 不值

## 跳槽决策自检

```
1. 我现在的能力在新机会里能复用多少？（>60% 才值得）
2. 新机会的行业 3 年后比现在好还是差？
3. 我的下一份工作，是「往上走」还是「原地换」？
4. 如果 3 年后回头看，这个决定我会后悔吗？
```

## 3 年后判断法

不要问「现在该不该跳」，问「3 年后回头看，我会为这个决定后悔吗」。把时间拉长，情绪噪音自动过滤。
