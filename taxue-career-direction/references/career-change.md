# 转行路径规划

> 转行不是「从零开始」，是把可迁移能力翻译到新行业。最难的不是学新技能，是证明旧能力在新场景有效。

## 转行难度地图

| 目标行业 | 难度 | 关键门槛 |
|---------|------|---------|
| 同职能换行业（如技术从电商到金融） | 低 | 行业知识 + 案例 |
| 同行业换职能（如金融销售到产品） | 中 | 新职能作品 + 思维转换 |
| 跨行业跨职能 | 高 | 可迁移能力证明 + 学习曲线 |

## 三条路径

| 路径 | 适用 | 关键动作 |
|------|------|---------|
| **内部转岗** | 现公司有目标岗位 | 先做好现职 + 主动承担新职能任务 + 找新部门 leader 表达意愿 |
| **边学边转** | 目标行业需新技能 | 项目制学习（做出作品/案例）而不是课程制（只听课） |
| **考证/认证** | 有硬门槛的行业（金融/医疗/法律） | 先考证再求职，证书是入场券 |

## 简历翻译法

把旧行业经历「翻译」成目标行业语言：
- 旧：「负责电商平台 DAU 增长」→ 新：「用数据驱动用户增长，DAU 从 100 万到 150 万」（数据保留，行业词替换）
- 旧：「管理生产线质量」→ 新：「建立质量管控体系，不良率从 3% 降到 0.8%」（底层能力一致，场景词换掉）

## 转行 5 大错误

1. 辞职后再转行（经济压力下仓促决策）
2. 只学不练（课程刷了一堆，没有作品）
3. 简历不翻译（用旧行业黑话，新行业 HR 看不懂）
4. 目标行业选错（凭想象选，没调研真实 JD）
5. 没有过渡期方案（转行期间的收入断档）

## 转行自检

```
1. 我要去的行业，3 个真实 JD 我读懂了吗？
2. 我的旧能力，能举出 3 个「在新行业有效」的例子吗？
3. 我有没有一个拿得出手的作品/案例？
4. 转行期间的经济缓冲够 6 个月吗？
```
